# Folio design context

Updated 2026-10-02. The maintained contract is [DESIGN.md](DESIGN.md).
This file is a short entry point; theme values and acceptance evidence belong
to that contract and its linked UI audit, not to a second palette here.

## Users and jobs

Chinese-speaking procurement, engineering and project staff. Windows desktop
work is keyboard and table heavy; Android supports field lookup and single
record entry; macOS is a secondary desktop. Preserve exact amounts, tax basis,
source evidence and explicit confirmation before AI/import writes.

## Visual direction

- Dify: bright neutral canvas, white surfaces, restrained blue actions.
- Grok: neutral dark greys with readable surface hierarchy.
- Claude: clear weight hierarchy, comfortable prose and limited reading width.
- DeepSeek Harness: consistent content typography and a focused assistant with
  explicit tool/evidence states. Bundle the open Noto Sans SC family; do not
  copy proprietary fonts or claim the reference uses this same font.
- Apple / Adobe: brief, continuous and interruptible feedback; honour reduced
  motion. Existing transitions must retain native back navigation behavior.
- Palantir Ontology: object navigation, relationship exploration and inspection.
  Fit the full diagram initially; zoom and selection must remain usable.

## Implementation constraints

Use existing Tokens and components. Keep tables dense and numbers tabular;
reflow inputs and actions with available width and text scaling. No gradients,
glow, decorative metric cards, duplicate theme layers or new dependencies.
Verify both appearances, small screens, large text, keyboard occlusion,
focus, empty/error states and recovery. Device acceptance and frame performance
require separate measurements beyond widget and browser checks.
