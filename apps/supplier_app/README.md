# Folio

供应商询价与项目成本。Folio 取意于资料页与文档集合，呼应蓝色折页品牌图标。

应用显示名、桌面窗口、Android 启动器、macOS 菜单与公司资料管理端统一使用 Folio。原应用 ID 保持兼容；Windows 保留用于旧资料目录的 ProductName 元数据，以便继续读取既有资料库。桌面程序文件名为 Folio.exe／Folio.app。
