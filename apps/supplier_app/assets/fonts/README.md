# Noto Sans SC

Source: https://github.com/notofonts/noto-cjk/tree/main/Sans/Variable/TTF/Subset

File: `NotoSansSC-VF.ttf` (17,773,132 bytes), downloaded from the official repository on 2026-09-30. The complete Simplified Chinese variable font is retained to cover imported supplier names, specifications and arbitrary user content without network font requests.
