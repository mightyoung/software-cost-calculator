# 第二步：问数据的证据与评测

基线：`codex/codex-agent` / `17632ae`。继续使用现有独立工作区。

## 验收目标

1. 兼容现有 `Store.ask`，增加可返回工具轨迹的接口；记录模型实际看到的有界结果，不保存隐藏推理，不新增服务或依赖。
2. 回答引用必须来自本次成功返回的结构化对象。原文备注、用户输入、历史答案中的 UUID 不算查询证据。未知引用降为不可点击的未核验文字；显示名称采用查询返回值。
3. 页面提供本次回答的查询依据；不把旧的仅文本历史标成已核验。默认不额外上传、持久化轨迹。
4. 新增问数据评测：任务是否调用正确领域工具、参数是否正确、引用是否有依据、是否保持只读、预算错误是否显式暴露。默认离线确定性模式，真实模型结果另行标记；不使用历史密钥、不运行真实付费调用。
5. 先补回归，再实现；运行受影响测试、静态分析及独立复核后提交。

## 参考与边界

[OpenAI Evaluate agent workflows](https://developers.openai.com/api/docs/guides/agent-evals) 建议先检查执行轨迹，再建立可重复的数据集；[Evaluation best practices](https://developers.openai.com/api/docs/guides/evaluation-best-practices) 将工具选择、参数和最终回答质量分开评估。本轮借鉴这些原则，用现有 Dart 接口实现本地评测，不引入云端评测平台。

引用核验只能证明对象被查询过，不能证明自然语言推论正确；证据面板显示原始工具数据供核对。多步查询可能处于不同时间点，不能冒充跨工具事务快照。本轮不开放 Agent 写入，不实现通用工作流或持久审计平台。

## 已实现

- `Store.askWithEvidence` 返回回答、实际工具参数/结果、轮数、耗时与引用警告；原有 `ask` 继续返回文本，经过同一引用核验。没有采集或展示模型隐藏推理。
- 只有工具定义明确的对象身份位置可以认证引用。备注、原文、旧问答、错误结果，以及超限后被丢弃的数据均不参与认证；未查询但存在于数据库中的对象也不能自动变成可信链接。
- 引用按对象类型与 ID 联合匹配，标签取查询结果的名称；未返回名称的记录使用领域类型名称，不采用模型自写的宣传性标签。
- 每条当前回答可展开“查询依据”，查看实际发送给模型的工具 JSON。历史文件仍只写原有三字段，不持久化轨迹；页面最多保留最近 6 份证据和 100 条消息。重新打开页面后，旧引用是普通文本，并说明未保留证据。
- `tool/assistant_eval.dart` 提供 8 个合成 SQLite 数据案例，经完整 Agent 循环回放，检查工具选择、参数、结果字段、引用、完成情况、只读不变性、证据与模型输入一致性。错误工具、参数、金额、引用和缺失轨迹均有负控制。

## 运行与结果

在 `packages/supplier_core` 下运行：

```sh
dart run tool/assistant_eval.dart
dart test test/assistant_eval_test.dart test/assistant_evidence_test.dart
```

CLI 输出 JSON，任何案例失败时退出码为 1。它明确输出 `mode=scripted_contract`、`replay_only=true`、`live_model_evaluated=false`，没有真实模型执行入口，也不要求或读取 API 密钥。

本轮验证：

- 核心完整回归 221 项通过；随后评分边界增强及证据专项共 17 项通过。
- 应用完整回归 92 项通过；最后的引用标签修复后，页面专项 12 项通过。
- 核心与应用静态分析均无问题，`git diff --check` 通过。
- 独立复核发现并修复：显示清理特殊字符产生未查询引用、同一对象使用伪造标签，以及金额评分接受符号/指数变体；均补反例回归。
- 离线 CLI 实测退出码 0，8/8 案例通过。精简原始运行结果见 [agent-eval.json](../verification/2026-09-29-agent-eval.json)。

页面在清理显示文本前固定本次已核验的对象与名称映射，清理不能新增可点击对象或替换名称。评测数字边界的增强仅是词法契约检查，没有提升为自然语言语义评分。

## 尚未声称完成的事情

- **真实模型的回答正确率尚未测量。** 8 个回放通过只说明本地契约与评分路径工作，不能转述为模型 100% 正确，更不是解析准确率 ≥90% 的验收。
- 评分器检查指定字段和完整数值片段，不能理解任意自然语言的否定、因果或误导；后续真实模型评测需增加人工标注任务集并审阅答案。
- 没有引用标记的普通文本仍可能包含幻觉；即使引用正确，推论也可能错误。界面明确这个边界，并提供实际工具结果供人核对。
- 运行晚期失败的工具轨迹可通过 `onObservation` 回调取得，但本轮页面错误消息暂不展示这些部分轨迹。页面离开或旧证据被淘汰后不再提供原始结果。
- 未增加模型 SDK、数据库 schema、业务服务器、付费模型调用或云端审计；在原有读取流程上增加两个轻量结果类型与测试工具。
