# 询价台账：功能与界面审查及优化计划（2026-09-28）

依据：逐页查看全部 21 张界面截图，另外临时生成了报价查询、供应商、物料三个列表页的截图；逐项核对代码（主题定义、字体、报错翻译、删除流程、列表上限、快捷键）；同时参照了之前两轮对标商用软件的调研。

对照对象：
- 桌面与移动端的设计：Linear、Things 3、Notion、Stripe 管理后台、飞书多维表格、Microsoft Fluent 2（Windows 11 的"设置"和新版 Outlook）。
- 采购类软件：SAP Ariba、Coupa、金蝶和用友的价目表与比价表、国内 SRM（甄云、企企通）。

范围沿用 [第二轮调研](2026-09-26-commercial-benchmark.md) 的决定，以下不在本计划内：供应商门户、审批流、采购订单、收货、外部行情。

## 总体判断

**核心业务逻辑已经扎实。** 包括：比价口径和有效价、定标、交换合并与冲突处理、智能导入、AI 数据层。

**问题出在界面还停留在"功能能用"的原型阶段。** 具体表现：
- 主数据页面空洞；
- 列表不能排序、筛选；
- 没有工作台和全局搜索；
- 品牌和字体规范没有落地；
- 大量英文报错；
- 删除没有确认也不能撤销。

这类软件的用户每天拿它和 Excel 对比。**目前表格能力弱于 Excel**，这是推广时最大的阻力。

## 一、功能性问题

### P0：影响数据安全或正确使用

| # | 问题 | 证据 | 建议 |
|---|---|---|---|
| F1 | 删除一键生效：物料、供应商、预算行删除时没有确认、没有撤销，红色删除按钮紧挨"保存"。数据库虽然是软删除，界面却没有回收站；删除失败时对话框直接关闭，不给任何提示。 | `catalog_page.dart:415`、`item_dialogs.dart:342` 的 `_delete` 直接写入并关闭对话框，忽略返回的错误 | 删除后在底部提示"已删除 · 撤销"（Gmail、Linear 的做法）；设置里加"已删除的记录"，可以恢复；删除供应商、物料前提示受影响的报价数量；删除按钮移到对话框左侧 |
| F2 | 列表静默截断：供应商、物料最多显示 200 条，报价查询不输入关键词时最多 300 条，没有任何提示。 | `catalog_page.dart:63/65`、`quotes_page.dart:95` | 分页或虚拟滚动，并显示"共 N 条" |
| F3 | 核心可能抛出的 128 种错误原因中，只有 15 种翻译成了中文，其余 114 种以英文显示给用户，例如"有效期至：requires quoted_on no later than valid_until"。 | 对比 `invalid()` 的所有原因与 `friendlyError` 的映射表 | 全部翻译，并加一个测试：核心新增的每一种原因都必须有中文 |
| F4 | AI 回答里夹着 UUID，提到的记录也不能点开。 | 系统提示要求"必要时附 id"；评测中的回答出现了 `ID c5b15c55-…` | 让模型用"记录标记"引用数据，界面渲染成可点击的记录卡片，并展示"查了哪些数据"（Perplexity、Notion AI 的引用方式） |

### P1：效率。Excel 用户会立刻拿来比较

| # | 问题 | 建议（对标对象） |
|---|---|---|
| F5 | 报价查询、物料、供应商都是单列文字列表：没有列，不能排序，不能按供应商、项目、日期、是否有效、含税口径筛选，也不能保存常用视图。 | 统一的数据表格组件：可选列、排序、筛选、分组、保存视图、导出当前视图、多选后批量操作（飞书多维表格、Airtable） |
| F6 | 没有供应商详情和物料详情。 | 右侧详情面板（Linear、Things 的详情栏）。供应商：报价历史、中标率、参与过的项目、联系人、最近报价。物料：价格走势图、各家报价、用过它的项目（SAP Ariba 的供应商 360 档案） |
| F7 | 没有全局搜索和命令面板。 | Ctrl+K：跨项目、物料、供应商、报价搜索，并能直接执行"新建报价""导入"等操作（Linear、Raycast、VS Code） |
| F8 | 没有工作台。即将到期的报价、待回复的询价单、待询价的预算行、修改冲突、数据质量问题，分散在 4 个页面里。 | 首页"今天要处理的"（Things 的"今天"、Linear 的收件箱） |
| F9 | 和 Excel 衔接不足：不能把 Excel 里的多行直接粘贴进预算表，也不能批量导入已有的供应商、物料清单（这是新用户上手的第一步）。 | 预算表支持粘贴多行，自动识别列；主数据批量导入复用智能导入的核对流程 |
| F10 | 键盘操作弱：只有 Ctrl+1 到 Ctrl+6 和 Ctrl+N；侧栏有 8 项，快捷键只覆盖前 6 项；预算表不能用方向键或 Tab 连续录入；对话框没有统一的 Ctrl+Enter 保存。 | 键盘优先：表格内方向键、Enter、Tab 连续录入；Ctrl+F 搜索；Ctrl+Enter 保存；Esc 关闭；快捷键一览（按 ? 打开） |
| F11 | 比价页是列表，不是比价表：交期、有效期、起订量、含税口径、价格包含的范围没有对齐成列；历史价只有一行小字，没有走势图。 | 列对齐的比价表，每列最优值高亮，附价格走势小图（Ariba、Coupa 的投标比较表） |
| F12 | 询价单只能导出 Excel。 | "复制询价消息"：生成可以直接发微信或邮件的文本；截止日前提醒；显示各供应商是否已回复 |

## 二、界面、交互与视觉问题

| # | 问题 | 建议 |
|---|---|---|
| V1 | **品牌没有落地**：三端的应用图标都是 Flutter 默认 logo；macOS 应用名、Windows 文件说明都显示 "supplier_app"。 | 设计正式的应用图标，统一使用"询价台账"这个名称 |
| V2 | **字体规范没有落地**：规范要求打包 IBM Plex Sans 和 Plex Mono，但实际没有打包；代码里用的等宽字体名 `monospace` 在 Windows 上基本不起作用，型号、编码仍按普通字体显示。12px 文字有 64 处，11px 及以下有 4 处；中文在 Windows 100% 缩放下，12px 已经偏小。 | 中文和拉丁字母都用系统字体：Windows 用 Segoe UI Variable 和微软雅黑 UI，macOS 用苹方，数字统一用等宽数字。只打包 IBM Plex Mono（约 100 KB），专门显示型号和编码。中文正文不低于 13px，12px 只用于辅助说明。同步修订设计规范 |
| V3 | **数字不是主角**：报价列表的价格挤在右侧角落，字号偏小；金额格式不统一，同一个预算页顶部写"¥186,820"，底部写"¥186,820.00"。 | 金额格式规则：指标取整显示，表格保留两位小数。关键价格用 15px 半粗体，右对齐成列 |
| V4 | **颜色语义不足**：只有一个强调色（科技蓝），同时承担选中、链接、主按钮、"最低价"和"已定标"；询价单矩阵里"最低"和"已定标"用的是同一种浅蓝底。设计中没有表示"好""成功"的颜色。 | 新增成功绿色，用于最低有效价、已定标、毛利为正；蓝色只用于可以交互的元素 |
| V5 | **侧栏**：选中项是饱和的蓝色大色块，和主按钮同色，抢视线；8 个入口平铺，其中三个名称里都有"数据"（问数据、数据交换、数据中心），容易混。 | 选中项改为浅色底加左侧指示条（Fluent 2、Linear 的做法）。分组：工作（项目、报价、供应商、物料）、智能（问数据）、系统（同步与交换、数据中心、设置） |
| V6 | **主数据页面空洞**：供应商列表只有名称一列，物料列表只有名称、型号和单位，页面大片空白。 | 表格化，加上信息列：类别、联系人、报价数、最近报价、最低有效价 |
| V7 | **重复和浪费**：预算页顶部指标条和底部合计栏展示同一组数字；比价页、冲突页有大片空白；询价单矩阵的列宽固定，右侧留白。 | 底部合计栏只在顶部指标条滚出视野后才出现；比价表和矩阵的列宽随窗口伸缩 |
| V8 | **表单**：字段单列、等宽平铺，没有分组。 | 相关字段并排两列（名称和单位、品牌和型号）；危险操作放到左侧或"更多"菜单里 |
| V9 | **Windows 原生感**：系统默认的浅色标题栏压在深色侧栏上方，视觉上被切开。 | 标题栏和侧栏融合，并可选 Windows 11 的 Mica 材质（需要新增一个窗口插件依赖，须经你同意） |
| V10 | **没有深色模式**。 | 基于现有颜色定义做一套深色配色，跟随系统设置 |
| V11 | **手机端**：项目列表信息太少；现场最常用的"快速录一条报价"没有显眼入口；"更多"里藏了 5 项；预算页顶部四个指标占了约 1/4 屏；导入核对页的底栏拥挤，一行摘要折成了四行。 | 首页加"录报价"主按钮；项目卡片显示待询价数和毛利；手机上指标横向排成一行；核对页底栏可折叠 |
| V12 | **问数据**：只是一个普通聊天框，等待时只显示"正在查询本机数据…"。 | 显示查询步骤；回答里的记录渲染成卡片；保留历史会话 |

## 三、优化计划

每一阶段都要求：新增或更新截图测试；界面改动需人工检查截图；设计规范文档 `.impeccable.md` 同步修订。

| 阶段 | 目标 | 内容 | 预估 |
|---|---|---|---|
| **1 · 修硬伤** | 试点前必须完成 | F1 删除确认、撤销和回收站；F2 分页和总数；F3 报错全部中文并加测试；F4 AI 回答去掉 UUID、改成可点击的记录卡片；V1 图标和名称；V2 字体；V3 金额格式；V4 语义色 | 3–4 天 |
| **2 · 表格与详情** | 追上 Excel 并超过它 | F5 统一数据表格组件，用于报价、物料、供应商；F6 供应商和物料详情面板，含价格走势图；F11 比价表按列排布；V5 侧栏分组和改名；V6、V7、V8 | 1–1.5 周 |
| **3 · 效率** | 键盘优先 | F7 Ctrl+K 命令面板；F8 工作台首页；F10 键盘录入；F9 粘贴 Excel 多行、批量导入主数据；F12 询价消息和截止提醒；V12 | 约 1 周 |
| **4 · 质感** | 可选 | V10 深色模式；V9 标题栏融合（新依赖）；V11 手机端；F13 PDF；F14 阶梯价；F15 供应商评价 | 约 1 周 |
