# v2 真机验收清单（一页）

适用平台：Windows、Android、macOS。每台设备记录应用版本、设备型号/系统版本、安装包来源、开始/结束时间和异常截图。Windows 与 Android 运行验证按本轮用户要求暂缓；本清单供之后直接执行，不代表已经通过。

| 步骤 | 操作 | 应看到的结果 |
| --- | --- | --- |
| 1 | 在三台设备分别安装并启动，设置不同的本机名称。 | 能打开空资料库；重启后数据位置和名称不变。 |
| 2 | 在设备 A 新建项目，填合同额、币种和税制；新建 5 种物料和 1 家供应商。 | 项目、物料、供应商可重新打开。 |
| 3 | 为 5 种物料各录 1 条有效报价，写明询价日期、价格、单位、币种、税制；在项目成本预算中各加入 1 条材料行，再加 1 条人工费。 | 5 条材料费和 1 条人工费按类别列出；记录页面与合计金额一致。记下材料小计、人工小计、总成本、对外报价与毛利。 |
| 4 | 在“报价查询”按供应商、项目或物料筛选；比较同口径报价。 | 筛选只显示匹配记录；不具备换算条件的报价明确说明不可比。 |
| 5 | 从项目详情导出“项目报价单”和“成本预算表”，分别用 Excel 或 WPS 打开。 | 中文、编号前导零、单价和金额小数位、5+1 行及合计与应用一致。记录所用 Office/WPS 版本。 |
| 6 | 从“报价查询”导出报价表，在 Excel/WPS 中改一条价格并保存，再用“导入报价表”预览、确认。 | 只更新目标报价；项目预算中已选单价快照不会无提示改变。重新导入同一文件不产生重复报价。 |
| 7 | 在 A 的“数据交换”导出 `.siq`，在 B 导入并确认；B 再导出，在 C 导入；最后 C 导出回 A。 | A/B/C 的项目、5+1 预算行、报价与合计一致；重复导入无新增；出现冲突时可见并人工核对。建议按 Windows → Android → macOS → Windows 的顺序记录结果。 |
| 8 | 在一台设备完成导入后强制结束应用并重开。 | 已确认数据仍在，项目与预算合计不变，资料库可正常查询。 |
| 9 | 在该设备额外新增一条本机记录，再选步骤 7 的旧 `.siq` 执行“从备份恢复整个资料库”。先看记录数预览，再完成第二次确认。 | 新增记录从当前库消失；旧快照的项目、报价、预算及合计恢复；“备份”目录留下恢复前完整副本。共享文件夹同步暂停，检查后才能手动重启。 |
| 10 | 从恢复前副本再次执行整库恢复，或在另一空设备导入该副本。 | 步骤 9 前新增的记录可以找回；两次恢复均未覆盖原 `.siq` 文件。 |

填写记录：A/B/C 各步通过、失败或未执行；步骤 3/5/7/9 的五个金额；步骤 6 的原价与改价；每个 `.siq` 的大小与导入耗时。若某设备暂缓，在记录中写 **DEFERRED**，不要写 PASS。
