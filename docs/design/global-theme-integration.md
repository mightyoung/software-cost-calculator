# 全局主题整合

更新于 2026-10-02。全局 `Tokens` 的深色画布、工作面、主文字与强边框已与数据中心本体视图统一。深色采用中性灰阶：画布 `#111111`、工作面 `#191919`、主文字 `#EEEEEE`、强边框 `#484848`。原生图谱从 `Theme.colorScheme` 取色，G6 与管理端同步相同语义值。导航和表格分组使用相邻中性色；蓝色继续表示可操作与选中状态，红、琥珀、绿保留业务含义。

浅色主题保持既有设计；导航注释色从 `#647086` 调整为 `#5B677B`，使其在悬停背景上也达到 4.5:1 对比度。深色次要按钮、错误按钮的文字改用深色前景，反色提示条的操作文字改用深蓝，避免亮底白字或亮底过淡文字。

Flutter 使用已有的开放可变字体 Noto Sans SC，保留中文平台回退。G6 与管理端仍使用系统字体。保留 24/16/14/13/12 的排版层级和数字特性，没有引入新字体或联网字体下载。

`test/theme_integration_test.dart` 验证两种主题的正文、注释、导航、主次操作、状态和提示条文字达到至少 4.5:1 对比度；验证输入框、对话框和全局工作面一致，以及深色全局与本体图工作面匹配。三个测试通过。此检查证明颜色配置和主题传递，不代表跨平台真机或视觉验收。
