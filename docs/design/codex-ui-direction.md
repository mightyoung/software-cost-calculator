# codex-ui 界面改版方向

范围：工作区壳、共享样式与高频业务页面。模式：**Operate**。用户此次授权整体 UI 分析和优化；本文件记录实现方向，不是用户对具体视觉方案的批准记录。

## 原有问题与响应

| 已检查问题 | 本次响应 |
|---|---|
| 深色侧栏成为最重色块，业务内容层级不够突出 | 浅中性色导航、白色工作面与克制蓝色 |
| 工作台 Ctrl+K 提示无法点击，触屏没有对应入口 | 真实搜索按钮，复用已有命令面板 |
| 手机任务名称与长截止状态挤在一行 | 窄队列将状态移至描述下方，标题与说明允许两行 |
| 项目页缺少页面标题，创建操作仅有小图标 | 明确标题、可读创建按钮 |
| 首个项目详情已显示，列表却没有对应高亮 | 实际详情项目决定列表选中态；筛选与详情一致 |
| 主从布局按整屏宽度判断，忽略侧栏和父容器 | 使用组件实际可用宽度，主列表继续保持 240 宽 |
| 项目筛选点击区域偏小 | 至少 48 高触达区域与选中语义 |

## 设计约束

页面标题统一使用 `titleLarge`。主动作直接可见；搜索和筛选必须真实可用。蓝色表示操作与选择，状态保留已有警告、错误和成功语义。桌面表格继续支持密集操作，手机调整结构与触达区域。所有金额、单位换算与预算计算继续使用既有逻辑，不为视觉效果改写计算模型或虚构指标。

## 文档和验证边界

根 `DESIGN.md` 记录当前 token 与组件，`PRODUCT.md` 记录已有产品事实。`.impeccable/design.json` 是设计面板扩展与 HTML 示意，不是 Flutter 样式来源，也不是截图证据。历史 `.impeccable.md` 保留不改，其深色侧栏和过时的 dark deferred 文案不能作为本分支当前依据。

新增 `apps/supplier_app/test/ui_task_surfaces_test.dart` 覆盖触屏搜索、列表与详情选择同步、受限宽度布局和筛选尺寸。测试结果、全量分析和截图检查以实际交付验证记录为准，本文不预先声明通过。

Windows、Android、macOS 真机、输入法、触屏、平台字体和 Office/WPS 仍需独立证据。目标平台、自动测试和截图不等于真机验收；保留 `docs/reviews/v2-device-validation-checklist.md` 的证据边界。
