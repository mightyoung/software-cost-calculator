# 采购研究助手：证据、资格与导入

## 目标与现有缺口

验证三条链路：按技术要求搜索物料与报价并审核导入；核对项目现有品牌型号的价格；不满足国产等条件时重新寻找替代品。基线为 `fa96fb4`，继续使用既有 Dart 工具循环、SQLite 领域模型和模型设置。

现有来源卡片只能证明访问过网址，不能证明模型填写的物料或价格出现在原文中。通用 CRUD 可绕过网页证据；未解析条款或未确认参数可能被匹配工具判为完全满足；价格性质和商务口径也没有研究阶段的门控。

## 设计决定

采用宿主提取事实、模型选择工具与候选、宿主报告和人工审核固定快照的流程。来源真实存在、页面声称某事实、真实世界事实属实是不同层次。目标是阻止助手自造事实进入采购结果与业务记录；网页本身的虚假信息仍需供应商、证书或人工核实。

替代方案是模型提取任意字段后附摘录：覆盖范围更大，但“摘录中出现某个数”不能证明该数属于目标型号或单价，故不作为自动导入来源。只增强提示也无法阻止绕过。

1. **可信来源与候选**：工具生成不可变快照，包含来源 ID、URL、时间、内容摘要散列、有界正文及完整性。只从明确关联的结构化 Product/Offer 或带字段标签的单产品记录提取事实；不同型号、冲突字段、区间价、起价或无法明确关联的信息保留未知。搜索摘要仅作发现入口。模型只选择来源/行 ID，不得提交新品牌、型号或价格值。当前支持范围外的网页返回无法形成可导入候选，不能补造。
2. **资格**：候选绑定原始要求及预算行版本，逐项列出支持、矛盾、未知。未解析条件、未确认必要参数、品牌国别与制造地的混淆，均不能成为合格结论。单独的“国产”若认定口径不明，须明确口径后再判断。重新寻料沿用全部原要求，不能静默放宽或继承旧物料参数。
3. **价格**：同品牌、完整型号/配置、币种、单位、数量门槛、税运和时间条件方可比较；缺失、过期及不一致样本列出排除原因。网页标价只作参考，不能自动当正式报价或完整采购成本。样本区间不等于市场公允价；样本不足明确无法判断。
4. **审核导入**：预览显示来源原文、字段、未知项、要求和实际变更；授权绑定候选与本机引用版本。确认后再次检查取消、权限、要求和关联记录版本。复用领域校验与原子回执，保存来源证据。研究工具仅导入基础资料及参考价，不直接替换已有预算关联；未知条件不能混入合格选型或正式报价。
5. **不可绕过**：采购事实必须经过该流程；通用物料/报价写入不得用任意 `values` 冒充研究结果。采购回答由宿主的结构化结果渲染，模型自由文本不作为已核验物料、价格或资格。保留通用页面导航及其它业务操作。
6. **恢复与边界**：来源和候选在本机按任务持久保存，最多 8 个来源和 8 个候选；任务恢复可重用真实快照，恢复全库后旧任务不能提交。无新增依赖、后台抓取或新托管代理服务；联网外发仍逐次确认。

### 架构审查后的强制合同

- 应用宿主固定启用采购事实保护，不依赖模型或关键词选择模式。新的问数据回答使用宿主报告；模型最终自由文本不作为采购事实显示或送入近期历史。普通本机查询可显示真实工具记录，未取得任何有效工具结果时明确没有核验依据。
- 通用工具禁止物料/报价创建和修改，禁止预算行的物料、报价、成本/售价及要求字段变更；模型不能通过预算行或清空要求绕过专门导入。删除/恢复及其它一般业务操作保留既有确认。
- JSON-LD 在同一次有界下载中提取并保留原始声明；Product 与其 Offer 不拆分拼接。缺失最小数量、单位、币种等时不导入报价；所有网络价格固定为 `reference`，不会自动成为项目成本或正式报价。
- 采购工具参数仅允许宿主候选 ID、预算行 ID和预设操作；审核绑定原要求与所有引用版本。资料库候选仍标为待人工核实。已有预算行的原物料、报价、成本及售价全部保留；替代品导入后明确“待重新询价”。实际替换须在现有预算流程中用可信正式报价完成经审核的完整重新定价，不能沿用旧物料成本、置零或把网络参考价补为预算成本。
- 来源缓存限制整个任务的序列化字节数，完成时可清理临时研究缓存；已导入的来源附件和回执永久保留作为业务证据。网页不实及不支持的网页格式明确列入验证边界。
- 来源快照将可见正文与 JSON-LD 分开保存，声明列表受数量、长度及摘要校验约束；正文不能通过内部标记冒充结构化声明或隐藏报价限制。旧格式中含有 `[Folio JSON-LD declaration]` 分隔标记的快照无法证明声明来源，恢复研究时需重新抓取；旧附件原文保留，但不再用于自动推定配置或报价事实。无标记的旧快照保留原编号及摘要。HTML 中普通小于号后的可见说明保留，未闭合标签或注释则明确标记来源不完整，不采纳价格。
- 物料的 `source_attachment_ids` 最多 8 条，受引用与附件完整性校验。schema 12 复用既有升级备份及迁移补齐旧字段，保留原记录版本和时间。物料及参数的选择导出携带实际来源附件，导入、全库恢复继续验证，不能只留下网址而丢失原文。
- 完整、加密及选择交换包保留已审核来源附件，不携带未审核候选、网页任务缓存、原始问题或本机助手回执。完整导出仅清理副本的精确运行状态前缀并 VACUUM，本机缓存保留用于恢复。
- 报价有效期按现有预算的业务日期判断；来源抓取时间仍为 UTC。不能在本机午夜因强制使用 UTC 的前一天而把昨日截止报价视为有效。

## 三类场景的实际支持范围

| 场景 | 当前可执行结果 | 无依据时的结果 |
|---|---|---|
| 按技术要求寻料、寻价并审核导入 | 搜索和抓取公开来源；提取明确单产品字段；逐条件核验；经人工预览导入物料、未确认参数、来源附件和有足够字段的参考价 | 网页无明确型号或无法支持价格时不生成报价；复杂未解析条件标为未知；候选仍待人工核实 |
| 核对项目当前价格 | 至少两个独立卖方、相同品牌完整型号/配置及商务口径的有效样本形成参考区间；与项目正式报价及成本匹配时输出精确单价差及区间位置 | 缺配置、税运、数量、日期，已过期或不同型号等列出排除原因；不输出市场公允价或自动判为合理 |
| 按原要求重寻国产等替代品 | 保留完整原要求，按制造地/品牌国别口径分别核验，审核后导入替代候选和参考价 | 无制造地证据不会因国产品牌判为国产制造；实际项目替换与正式重新定价须走预算流程，不继承旧物料成本 |

使用“问数据 → 助手权限”或“设置 → AI 接入”开启联网并选择国产认定口径。每个不同外发搜索词/URL需确认；只读权限允许研究但拒绝导入。提供具体项目或预算行及要求，例如“按泵房项目的技术要求搜索国产制造候选，逐项列出原文和未知，审核后导入资料”，或“核对这条预算行的完整品牌型号、配置和报价口径，只比较可比参考价”。未提供清晰业务对象或网页不支持时，助手保留未完成结果，不自行补齐。

## 官方依据与事实边界

OpenAI 的 [Structured Outputs 文档](https://developers.openai.com/api/docs/guides/structured-outputs#handling-mistakes)明确区分结构正确与内容错误，并建议对无法处理的输入返回空值或明确提示；[Agent Builder 安全文档](https://developers.openai.com/api/docs/guides/agent-builder-safety#combine-techniques)强调组合结构化数据、隔离不可信输入和工具批准。本实现将批准和字段绑定置于宿主，不让网页指令或模型填写权限。

[Web search 文档](https://developers.openai.com/api/docs/guides/tools-web-search#output-and-citations)支持保留引用与来源；引用本身不足以证明价格属于某个完整型号。本实现增加同页 Product/Offer 绑定和价格口径校验。评估按 [OpenAI evaluation best practices](https://developers.openai.com/api/docs/guides/evaluation-best-practices#design-your-eval-process)覆盖常见、边界和对抗输入，而不是仅验证成功演示。[Claude 权限设计](https://code.claude.com/docs/en/permissions#manage-permissions)作为显式权限与审批的参考；本机权限无法由模型更改。

这些控制能阻止已覆盖路径中模型自造字段被展示为核验结果或写入采购数据，不能保证供应商网页属实、所有网站都可解析，或所有自然语言条件都能自动判定。没有使用真实模型的端到端市场评测来证明普遍准确率；离线场景测试及公网访问证据分别报告。

## 验证计划与失败情景

- 无网页、伪造来源/行 ID、无关页、型号 A 与 A-Pro 混用、总价冒充单价、起价/区间价、多产品混页、重复或相互矛盾字段：不形成可导入报价。
- 缺参数、纯文本硬要求、未确认参数、国产品牌但海外制造、裸“国产”口径未定：不能判为完全满足；重新搜索保留原条件。
- 缺税运/数量/日期、过期、单位币种不同、配置不同、卖方相同的重复样本：不输出无依据的价格合理结论；保留未知和排除原因。
- 正常路径：固定网页数据 → 可信候选 → 三场景结构化报告 → 拒绝/确认 → 原子导入与来源持久化。模型最终回答即使故意编造型号、价格或资格，也不能污染可信报告。
- 取消、重复调用、批准期间预算/关联记录变化、断点恢复、全库恢复、无权限：零未授权写入，至多一次提交。
- 已有物料 A、正式报价 A、非零成本的预算行，面对合格替代品 B 及网络参考价 B：拒绝直接替换和通用字段写入旁路；批准导入仅保存 B 的来源资料，原预算行逐字段保持。
- 核心与 Flutter 专项测试、分析和适当完整测试；实际网络只证明工具及页面访问，不冒充真实模型或市场准确性的证据。

实施前以独立架构审查检查证据关联、旁路和不可证明的资格；实施后独立审查及测试验收。只有字段支持正确、未知不误通过且无未授权写入，才达到这三种场景的交付门槛。
