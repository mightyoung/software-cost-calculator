# 界面设计规格（v1）

设计语境、色板与原则见仓库根目录 [`.impeccable.md`](../../.impeccable.md)。可视原型见 [`prototype.html`](prototype.html)，用浏览器直接打开即可，共三屏：Windows 项目成本预算、按清单建项目的核对页、Android 项目预算。

## 1. 信息架构

| 桌面导航（左侧 176px） | Android 底部导航 | 内容 |
|---|---|---|
| 项目 | 项目 | 项目列表 → 项目详情（成本预算 / 报价记录 / 变更记录） |
| 报价查询 | 报价 | 组合筛选、同口径比价、报价录入 |
| 供应商 | 更多 › 供应商 | 供应商、联系人及其报价 |
| 物料 | 物料 | 物料库及每个物料的可用报价 |
| 数据交换 | 更多 › 数据交换 | 导出/导入交换文件、Excel 模板、备份即交换文件 |
| 设置（底部） | 更多 › 设置 | 本机名称、AI 接入、诊断信息 |

全局入口：
- **新建报价** `Ctrl+N`：从任何页面都可打开，默认选中当前项目。
- **搜索** `/`：聚焦当前列表的搜索框。
- **从清单生成项目**：项目列表页顶部，以及项目详情工具栏。

## 2. 版式与组件

- **台账行**：替代指标卡片。一条上下细线之间，放 4 个等宽区，每区由标题（12px）和数值（20px/600）组成。预警文字直接写在对应数值下方。
- **分组台账表**：
  - 表头：浅底、12px/600，吸顶；
  - 分组行：写类别名和项数，并在成本金额、对外金额两列给出小计；
  - 明细行：第一列为名称（500），下方用等宽字体写型号或规格；
  - 数值列：等宽、右对齐、不换行；
  - 底部合计栏：2px 墨色上边线，吸底。
- **提示标签**：图标加文字，琥珀色（警示）或朱砂色（错误），不单靠颜色区分。
  - 文案固定为：更低价 ¥x、报价已过期、待询价、数量待填、成本达合同 91%。
- **虚线约定**：凡是"尚未确认"的内容一律用虚线框，包括 AI 匹配、导入预览、交换预览。确认后变为实线。
- **按钮**：每个视图最多一个实心主按钮（铜绿色），其余为描边按钮。按钮文案动词在前：添加物料、生成项目（6 项）、导出交换文件。
- **未知不写 0**：未知价格显示"—"，合计旁注明"含 1 项待询价，未计入"。

## 3. 核心页面

### 3.1 项目列表与详情（桌面）
三栏布局：导航 176px、项目列表 240px（可按 `Ctrl+B` 收起）、详情区。

- **项目列表**：
  - 每项显示编号（等宽）、名称、客户、成本合计；
  - 有预警时在右上角显示琥珀三角和数量；
  - 顶部为状态筛选胶囊：进行中 / 策划中 / 全部。
- **详情区**：
  - 页头：编号、状态、级别与类型；项目名 20px；元信息行写客户、负责人、合同号，以及币种和含税口径；
  - 页头下方是台账行；
  - 工具栏：左侧页签，右侧"从清单生成""导出▾""添加物料（主）"。
- **表格内编辑**：
  - 数量和单价单元格可直接编辑，`Enter` 下移、`Tab` 右移；
  - 改动的单元格在保存前显示虚线下边框，失焦即保存；
  - 保存后刷新小计和台账行。
- **行操作**（右键菜单或行尾"⋯"）：更换报价、复制到其他项目、查看报价历史、删除。

### 3.2 添加物料（右侧抽屉，480px）
1. 搜索物料（型号、名称、品牌、规格）。每条结果显示最低有效报价、供应商和有效期状态，以及"有效期待确认"标记。
2. 勾选多个物料，并逐个填写数量。
3. 点"加入预算（N 项）"。默认带出最低有效报价，可展开改选其他报价。
4. 库里没有的物料，点"作为待询价添加"，只需填名称、要求、数量和单位。

### 3.3 按清单建项目（三步）
1. **输入清单**：可粘贴文本，也可拖入或选择 Excel 文件。
   - 右侧说明会发送哪些内容：清单文本，以及候选物料的名称和规格，不含价格；
   - 未配置 AI 时，页面给出"去设置"的入口。
2. **核对匹配**（见原型第 ② 屏）：
   - 左侧为清单原文，带行号；点右侧某行，高亮对应原文；
   - 右侧为虚线框表格，列为：清单项、匹配物料（可下拉改选候选或"作为待询价"）、把握（高/中/无 + 理由）、参考报价、数量（可编辑）；
   - 需要注意的行在左缘显示琥珀色竖条，可用筛选胶囊单独查看；
   - 数量存疑时（原文写"约""若干"），在数量下方标出原文；
   - 底部表单：项目编号（自动建议）、名称、客户、加价率；右侧"返回修改清单""生成项目（N 项）"。
3. **生成项目**：在一个事务内写入，然后跳到项目详情，并提示"已生成 6 项，其中 1 项待询价"，附"导出询价清单"入口。

处理中的状态：
- 分段显示进度，例如"正在整理清单（第 1/2 段）""正在匹配物料（15/42）"；
- 可以取消；
- 出错时说明原因并给出重试，例如：
  - 网络不可用，检查网络后重试；
  - AI 返回格式异常，已重试一次，请稍后再试。

### 3.4 报价查询与录入
- **筛选栏**：物料/型号、供应商、项目、询价人、报价日期范围、口径（币种 + 税制）、"仅有效报价"开关。
- **结果表**：按报价日期倒序；选中一个物料时切换为比价视图，同口径最低有效价排第一，过期和口径不同的报价灰显并注明原因。
- **新建报价**：单页表单，分三组。
  - 报价内容：供应商、物料、单价、口径、起订量；
  - 询价信息：项目、询价人、询价日期（系统日期选择器，可选"仅日期 / 具体时刻"）；
  - 有效期与备注。

  必填项在提交时一次性列出，并定位到第一个错误。

### 3.5 数据交换
页面上只有两件主要的事，各占一块并列：
- **导出交换文件**：显示上次导出时间；点击后调用系统"另存为"，默认文件名 `询价台账-采购部01-2026-09-23.siq`。
- **导入交换文件**：选择文件后显示预览，内容包括：新增 N、更新 N、无变化 N、两端都改过 N（可展开明细）；再点"确认导入"。

下方为次要入口：
- Excel 报价模板：导出、导入、下载空模板；
- 从交换文件整体恢复：二级确认，并说明当前数据会先自动导出一份。

### 3.6 设置
- **本机名称**：用于交换文件名和变更记录。
- **AI 接入**：
  - 服务地址（默认 DeepSeek）、模型名（默认 deepseek-flash）、API Key（密码框，保存在系统安全存储中，不进入数据库和交换文件）；
  - "测试连接"按钮；
  - 说明会发送哪些数据。
- **诊断信息**（折叠）：数据库位置、记录数、版本号。这是唯一出现技术字段的地方。

## 4. Android 适配

- 底部导航 4 项：项目 / 报价 / 物料 / 更多。
- 项目详情：
  - 顶部是两列汇总格（成本 / 报价 / 毛利 / 合同）；
  - 下方按费用类别分段列表；每行左侧名称和型号，右侧金额和"数量 × 单价"；
  - 合计与"添加"按钮固定在底部。
- 录入：分步表单，每步一屏：物料 → 价格与口径 → 询价信息。数字键盘自动切换。
- 按清单建项目：同样三步；核对页改为逐项卡片，左右滑动切换，底部显示"第 3/6 项 · 2 项需确认"。
- 文件：导入用系统文件选择器（SAF），导出用系统"分享"，可直接发送到微信或邮件。
- 触控目标不小于 48dp，列表行高不小于 56dp。

## 5. 状态与文案

| 场景 | 文案 |
|---|---|
| 空项目列表 | 标题"建立第一个项目"；说明"项目用来汇总报价与成本预算，可从客户清单一键生成。"；按钮"新建项目""从清单生成" |
| 空预算 | 说明"这个项目还没有物料"；按钮"添加物料""从清单生成" |
| 导入无变化 | 这个文件的内容本机都已有，无需导入 |
| 两端都改过 | 以下 3 条记录在两台设备上都被修改过，已采用较晚的修改。可在变更记录中查看另一版本 |
| AI 未配置 | 按清单建项目需要先配置 AI 服务 → 去设置 |
| 网络失败 | 连接 AI 服务失败：网络不可用。检查网络后重试 |

文案规则：
- 不出现"成功""请"；
- 按钮动词在前；
- 错误提示先说发生了什么，再说怎么办；
- 不使用感叹号。

## 6. Flutter 实现映射

- `ThemeData`：
  - `ColorScheme` 由 `.impeccable.md` 的色板手工指定，不用 `fromSeed`，避免 Material 自动生成的紫色系；
  - `useMaterial3: true`，但圆角统一为 6px，阴影为 0。
- 字体：
  - 打包 IBM Plex Sans（Regular、SemiBold）和 IBM Plex Mono（Regular），`fontFamilyFallback` 依次为 `Microsoft YaHei UI`、`PingFang SC`、`Noto Sans SC`；
  - 数字统一使用 `FontFeature.tabularFigures()`。
- 自绘组件（Material 默认组件密度不适合）：
  - `LedgerStrip`：台账行；
  - `LedgerTable`：分组、吸顶表头、合计栏、单元格编辑、键盘导航；
  - `HintTag`：提示标签；
  - `DraftFrame`：虚线框，用 `CustomPainter` 实现。
- 自适应：宽度 ≥ 1024 用三栏；600–1024 用两栏，项目列表改为抽屉；< 600 为手机布局。
- 快捷键：用 `Shortcuts` / `Actions` 注册 `Ctrl+N`、`/`、`Ctrl+B`、`Esc`。
- 可访问性：每个提示标签提供 `Semantics` 标签；焦点环为 2px 铜绿色；支持系统文字缩放到 130%，表格随之横向滚动，不截断文字。
