# 公司资料中心管理端

用户要求在已有页面基础上完成管理端/服务端前端设计与开发。本批在 `codex-backend` 的 Rust 中心服务内提供浏览器界面，前后端同源、一个二进制部署。

## 页面依据

沿用 `.impeccable.md`、`apps/supplier_app/lib/app/theme.dart` 与 `shell.dart`，以现有供应商、报价、设置页面为参照：176px 深蓝导航、蓝灰底色、8px 圆角、20/16/14/13/12px 字号、表格优先、统计条而非指标卡片。数字保留原始精度；草稿预览用虚线，确认数据用实线。窄屏导航换行、表格内部滚动，详情为全宽抽屉；深浅色跟随系统。

## 页面与真实行为

| 页面 | 行为 |
| --- | --- |
| 工作台 | 共享资料、保留版本、接收账本和本地已投递版本统计，常用工作入口 |
| 供应商 | 名称/评价说明检索、分页、已撤回筛选、正文和关联资料、发布历史 |
| 历史报价 | 原始十进制价格、币种/计价单位/税价口径、供应商和型号、日期与起订量；不自行平均或换算 |
| 发布资料 | 选择文件 → 无写入的服务端校验 → 核对正文/范围 → 勾选确认并发布；不自动上传客户端数据库 |
| 同步与交换 | 来源目录到内网目录的单向流程、本中心角色、最近本地任务计数/错误；没有远端回执 |
| 服务设置 | 运行配置只读展示、连接管理、备份说明、折叠诊断；修改 TOML 并重启才变更服务配置 |

详情允许对本中心当前版本明确撤回或恢复，每次产生新版本。旧版和外部来源不能通过此操作改写。409 冲突要求重新读取；发布重试保留原身份。必要关联以实体类型和 UUID 联合匹配，避免合法的跨类型同 UUID 错名。

## 实现边界

- `services/supplier_hub/web/`：原生 HTML/CSS/JavaScript，无新增运行依赖、CDN 或前端构建器；由 Rust `include_str!` 嵌入。Node 22 只用于开发测试。
- `src/web.rs`：精确静态路由及 CSP；不把未知路径当作页面。
- `POST /v1/publications/preview`：规范化并验证完整发布合同，不读取/写入数据库。
- `include_withdrawn` 默认 false；报价摘要从快照内提取供应商名称、物料型号/品牌和项目名称，避免列表逐行查询。
- 令牌只在页面内存，断开时中止请求并清除业务视图；认证代次隔离旧请求。没有账号平台、持久令牌或任意远端地址输入。
- 所有业务内容经文本节点呈现；正文链接仅显示文本。原始资料及技术标识位于折叠诊断中。
- 发布完成回执属于操作状态，不依赖当前页面；离开再返回不会丢失完成结果。失败不冒充成功。

## 验证记录

本机 macOS ARM64：21 项 Rust 测试（含 1 项摘要单元测试及 20 项集成测试）、Clippy `-D warnings`、fmt、构建通过；5 项 Node 测试验证精确价格、版本操作边界、失败报告、枚举翻译边界及引用身份。

使用独立临时数据库与示例资料进行浏览器实测：错误令牌、重新连接、空列表、选文件预览与明确发布、撤回确认、包含撤回筛选、旧版本只读、恢复共享、报价精度和关联名称、23 条供应商分页与搜索、窄屏同步页、断开清空内容。测试数据不写入原客户端数据库。

独立源码复核发现并修复：发布过程中切页丢失回执，以及只按 UUID 解析关联名称。Web 前端不是上一批已封存安全扫描的覆盖结论；本批采用接口回归、浏览器验证和独立代码复核。Windows/Linux CI 已配置，尚未远程执行；真实单向设备与目标部署权限仍需验收。

本批不包含 Flutter 内的中心资料页、账号权限平台、附件交换、自主选型或 Web 修改服务配置。
