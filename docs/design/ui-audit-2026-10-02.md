## 已证实的问题与修复

| 问题 | 修复与覆盖 |
| --- | --- |
| 暗色偏暖棕，与本轮 Grok 中性灰阶方向不符 | 统一 `theme.dart`、G6 CSS 与管理端 CSS；原生关系图改从 `Theme.colorScheme` 取色；正文与状态对比度回归通过 |
| `.impeccable.md` 仍规定海军蓝侧栏、平台字体、蓝黑暗色 | 改为 `DESIGN.md` 的短入口，移除冲突 token 和过时字体声明；补齐 DeepSeek Harness 的参考边界 |
| 助手五行草稿在 320×640、2 倍文字和 260px 键盘下溢出 47px | 根据剩余高度与缩放行高限制可见行数；长草稿内部滚动；浅深主题均测试发送按钮在键盘上方 |
| 物料属性值输入在 220px 容器内仅有 24px 宽 | 窄屏纵排名称和值，说明移至标题下方；测试输入可编辑和删除回调 |
| 参数标题和模板建议在大字窄屏下水平溢出 | 标题/计数/确认使用 Wrap，模板与建议纵排；覆盖草稿确认不提前写库 |
| 交换口令卡片的操作挤压说明 | 按可用宽度和文字倍率纵排说明与动作，动作允许换行；覆盖 320/390、150% 字体、设置/未设置状态及取消保留口令 |
| 图谱强制最低初始 75% 缩放裁掉两侧节点 | 采用完整 fit；原生测试检查所有节点水平边界；G6 窄屏初始布局允许完整缩小 |
| 原生图小于 100% 时仍显示 100%、缩放步进错误 | 变换矩阵 XYZ 同比缩放，符合 InteractiveViewer 的最大轴缩放计算 |
| G6 窄屏对象选择位于画布下方，需滚动才能选择 | 在隐藏目录时把当前对象选择放到顶部工具栏，选择后聚焦对象 |
| 最终审查发现完整缩小后显式聚焦只平移、节点仍太小 | 用户主动聚焦时先提升至至少 85% 再居中；保留更近的用户缩放；减少动效可中断缩放及后续平移 |
