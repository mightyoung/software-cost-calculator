所有页面提供跟随系统 / 浅色 / 深色选择，仅在当前页面生命周期有效，不持久化访问令牌或新增存储。浅色 `#F7F8FA`、深色 `#131211` 及正文/边框/状态色对应根设计基准。SVG 直接内嵌已有图标目录的路径，测试核对几何一致，无新字体包、资源端点或运行依赖。导航、刷新、关闭图标跟随 `currentColor`。

正文与标题使用 rem，控件最小 44px，导航 48px；390px 时六个入口排列为可增长的三列网格。表格、分页、面板标题、页头按钮、连接弹窗各自处理可用宽度，不隐藏整页溢出来掩盖问题。交互仅增加 120ms 背景/边框变化，尊重减少动态效果。原生 dialog 保留 Escape、焦点约束和关闭入口。

## 本地浏览器验收样本

从仓库根目录执行：

```sh
node services/supplier_hub/web/review-server.mjs 8782
```

- 桌面：`http://127.0.0.1:8782/admin/`
- 390px iframe + 140% 根字体：`http://127.0.0.1:8782/review`
- 两个页面都显示设计样本提示。仅使用 Node 自带模块，绑定本机地址，不连接真实服务或数据库。
- 点击导航：工作台、供应商、历史报价、发布资料、同步与交换、服务设置。每页分别选择浅色/深色，检查页宽、颜色、文字与操作换行。
- 供应商列表点击“华东精密设备供应商 · 设计验收样本”，历史报价点击“不锈钢离心泵”，检查详情/发布历史/诊断折叠区、关闭及 Escape。
- 搜索无匹配关键词检查空态；Ctrl/⌘ K 回到搜索；Tab 到列表区域后左右键滚动，核对长金额未截短。
- 点击“连接管理”检查连接、断开、密码清理和窄屏按钮；样本服务不校验实际令牌，因此不构成认证验收。
- 发布页可选择客户端格式 JSON 样本，检查预览与未勾选时禁用提交。样本 POST 仅修改此临时进程内数组，不代表真实落库、版本冲突处理或交换接收成功。
- 同步页内置失败样本，以便审阅错误提示与重试入口。

样本服务器不会进入 Rust 的嵌入式资源路由；生产仍只使用原有 index.html、app.js、styles.css 三个端点。
