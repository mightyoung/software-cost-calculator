# 询价台账 · 统一业务图标

这套图标为本项目原创矢量路径，采用同一 24×24 坐标系、1.7 单位描边、圆形端点和连接点。没有使用第三方素材、商标或生成位图，不需要新增运行依赖。

## 交付与应用

- `index.html`：可切换 16/20/24/32px 的亮暗并列对照页；包含导航与操作场景。
- `svg/`：每枚图标独立 SVG，可编辑、可缩放；使用 `currentColor`。
- `sprite.svg`：网页用 SVG symbol 集合。
- `catalog.json`：唯一图形源，包含业务名称、分组、路径和现有 Material 标识的迁移映射。
- `apps/supplier_app/lib/widgets/app_icon.dart`：Flutter Canvas 渲染，继承 IconTheme 的颜色、透明度、尺寸和文字缩放，保留语义标签与方向性。
- `apps/supplier_app/lib/widgets/icon_paths.g.dart`：由图谱生成的 Flutter 路径，不要手改。

现有页面通过 `AppIcon` 使用新图形，业务操作与路由保持原样。保留 Material 标识作为迁移键，因此代码中仍能看到 `Icons.factory_outlined` 等名称，但屏幕实际绘制的是新企业名录图形。未知图标有默认回退；覆盖测试检查目前代码中的图标名称均有映射。

## 业务决定

供应商使用企业名录，覆盖制造商、经销商与服务商；报价使用带价格符号的单据；问数据使用数据条形与对话轮廓；数据中心使用资料存储；智能导入使用扫描文档，避免把“星星”用于所有智能功能。待询价使用报价单与问询轮廓，帮助仍保留问号。

导入、导出、恢复、删除、确认等图形沿用常见动作方向。询价、最低报价、报价失效等业务状态必须附文字，不能把信息压缩为一个颜色或箭头。

## 明暗一致性

两种主题共用一份路径，不能分别生成光影或修改形状。图标不包含底色，不内置蓝色、黑色或白色；主按钮继承按钮前景，告警继承 warning，禁用状态继承 IconTheme opacity。图标自身不切换主题、不读取系统亮度。

网页使用内联 SVG 或 `<svg><use href="sprite.svg#quotation"/></svg>`，由父元素设置 `color`。不要用 `<img>` 外链方式期待 SVG 自动继承页面文字色；独立 SVG 下载文件默认显示黑色，编辑器中可修改描边。

对照稿沿用上一轮确定的 Dify 方向亮色与 Grok 方向暗色。Flutter 图标已接入现有主题，但上轮提出的整个生产主题和布局重构仍未实施，不能把本轮图标替换称为全系统第二版重构完成。

## 维护与验证

```sh
python3 apps/supplier_app/tool/generate_business_icons.py
python3 apps/supplier_app/tool/generate_business_icons.py --check
```

先改图谱，再运行生成器，检查小尺寸和两种主题。不要让网页样稿与 Flutter 各自维护不同的图形。Flutter 测试覆盖路径绘制、主题透明度、文字缩放、RTL、语义与调用覆盖；原生 Windows/Android 实机视觉验收仍需单独执行。

本轮范围为应用内部功能图标；系统启动器图标与应用商店图标仍沿用原资产。
