# 助手联网与应用操作

基线：`codex/codex-agent` 已快进到 `origin/main` 的 `586adf4`。保留 Dart 领域工具和兼容 OpenAI 的模型设置，不迁移数据库或新增代理平台。

## 实现与验收

1. 在现有有界工具循环中加入应用明确注入的异步工具；禁用能力不提供给模型，执行器继续检查白名单、参数、调用次数和取消。
2. 独立开关允许联网。界面在每个不同的外发搜索词或网址请求前显示内容并要求确认；拒绝不发出请求，同一任务只复用完全相同请求的许可。搜索与公开网页读取保留标题、URL、时间、截断信息；限制 DNS、地址、重定向、响应体和正文长度。网页内容不能授权任何操作。
3. 应用操作覆盖业务记录的创建、修改、删除和页面入口。默认逐次确认，另有只读模式；权限不可由模型修改。高风险的恢复、交换、凭据等功能打开现有页面，沿用其人工流程。
4. 写入预览绑定参数和当前数据库状态；确认后检查取消与版本，以既有领域事务提交。审批拒绝、过期、取消不写入；持久回执阻止恢复重放重复提交。
5. 确认界面展示具体字段变化和删除影响；联网来源可点开；本机对话继续默认不外发历史。
6. 验证工具注入、禁用、来源处理、SSRF/大小/超时/取消、确认拒绝/接受/过期、恢复幂等；运行核心及 Flutter 测试与分析。

## 交付行为

在“问数据”右上角的“助手权限”菜单，或“设置 → AI 接入”，选择只读/修改前逐次确认并开启联网。默认逐次确认写入、联网关闭。无需新增搜索密钥；公开检索使用 Bing RSS，服务不可用时明确返回错误，不切换模型或泄漏密钥。

`web_search` 返回来源；`web_fetch` 读取公开 HTTPS 网页；`web_extract` 从本任务已读取的页面提取关键词段落，再由模型整理、比较和总结。只连接已校验并固定的公网 DNS 地址，每个重定向重新检查；限制响应 512 KiB、请求 20 秒、缓存 8 页和最多 8 条搜索结果。HTML 使用顺序扫描，避免畸形标签让正则阻塞界面。来源卡片可打开系统浏览器或复制链接。

`create_record`、`update_record`、`delete_record`、`restore_record` 覆盖供应商、联系人、物料、项目、预算条目、询价单和报价。确认期间记录或关联数据改变时拒绝旧预览。删除移入回收站。每次提交与有界回执原子落库；任务重试返回原回执且不重复修改。模型后续失败或任务停止时，界面仍展示已确认保存的操作。`app_pages`/`open_page` 覆盖应用页面和实际可打开的业务记录；同步、恢复、导入导出、发布和设置沿用对应人工流程。

当前行为没有任意代码、任意 SQL、文件路径、凭据变更或自动后台发布工具。联网来源是外部证据，不能自行转成已确认的业务数据。部署和跨平台浏览器启动不属于本次本地测试证明范围。
