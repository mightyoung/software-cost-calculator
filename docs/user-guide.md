# 供应商与询价使用指南

更新：2026-09-27。适用于当前开发候选，验证范围见[发布验收矩阵](verification/release-matrix.md)。Android、Windows 实机验证按用户要求延期；本文描述已连接的操作流程，不代表所有平台均已验收。

当前核心 534 项、应用 116 项自动化测试及静态分析通过，Web release 构建和隔离 Chrome 存储运行时验证通过。最终代码审查为 APPROVE，架构审查为 CLEAR；本地工作流集成测试因缺少可用目标未执行。注入文件句柄的浏览器业务导入和完整同步界面流程、正式适配器的安全备份重开已有通过证据；真实 Excel/WPS 保存回流、系统文件选择器和完整界面恢复尚未独立验收。正式发布仍未放行，具体日志与范围见矩阵。

## 开始使用

应用在本地保存供应商、联系人、产品和报价，不需要登录，也不会自动联网同步。设备间交换由用户主动导出、传递和导入文件。

Android 已接入系统提供的应用支持目录作为默认存储位置；实际 Android/Windows 安装与持久化验证仍按要求延期。

浏览器数据属于当前站点和浏览器配置。清除站点数据会删除本地资料；请把完整备份保存到站点存储之外。看到“只读模式”时先查看原因并使用“重试”，不要把尚未保存的输入当作已入库。浏览器离线重开、资源升级和完整同步文件选择路径尚未全部验收。

## 录入与查询

1. 在供应商页面新增供应商；切换到“联系人”后新增联系人，并选择所属供应商。联系人电话、微信、邮箱至少填一项。
2. 在产品页面新增产品，填写名称、品牌、型号、规格等实际资料。
3. 点击“新增报价”，选择供应商与产品，逐步填写报价、项目与询价信息，再点击“保存”。项目名称和编号至少填一项；标准报价需要询价时间、询价人及报价日期等必填信息。零价可以填写为 `0`，不能用空白表示已知价格。
4. 询价时间选择“仅日期”或“具体时刻”。具体时刻须明确原始地点时区，保存前核对确认窗口；不要用当天日期代替未知历史日期。报价日期与询价时间分别填写。

金额使用十进制文本，最多六位小数。编号、电话中的前导零要保留；在外部表格中把这类列设置为文本，避免表格软件先改变原值。

在“查询与比价”输入关键词并搜索，可切换“全部记录”“每家最新”“有效最低价”，或使用“历史缺失”“组合筛选”。比价按产品、单位、币种、税制、起订量分组；异常关联及有效期待确认的记录不参与最低价。

打开详情后，“编辑记录”用于纠正原记录；“复制为新询价”创建新记录，并按标准报价要求补齐信息。同内容的新询价可以合法存在。删除前核对影响提示，删除会保留历史，不是清除历史修订。

## 业务 Excel 导入与导出

进入“文件与备份”。业务 Excel 用于日常表格编辑；完整同步包用于交换完整历史；完整备份用于恢复资料库。三者用途不同。

导入流程：

1. 打开“导入业务 Excel”。原生界面当前要求输入文件完整路径；浏览器使用文件选择器。读取文件后选择工作表，点击“解析选中工作表”。
2. 核对标题行号与列映射。标准报价使用“标准报价”；仅在导入真实旧资料时选择“历史资料（明确允许上下文缺失）”。批次默认值只能填写本批资料真实适用的值。
3. 点击“确认映射并查看转换预览”。检查每行的原始单元格、转换结果、日期系统、候选记录、当前值与导出基线。需要转换确认时，核对后明确接受。
4. 对每行点击“核对并选择操作”，明确选择目标、新建、跳过或排除错误行。修改已有记录时，空白来件默认保留当前值；清空必须选择“明确清空”。没有可靠编号或本机回执时，人工核对候选，不依赖名称相同自动合并。
5. 点击“查看最终汇总”，核对应用、跳过、排除行数及结果数量，再点击“确认汇总并提交导入”。逐行决定尚未写入业务资料；最终确认后先创建并校验备份，再提交选定内容。

导入页显示任务编号，可保存该编号后用“恢复导入任务”继续。已经封存的决定需要调整时，应新建任务。相同来源再次导入会显示已有成功选择；明确重新处理前先核对旧回执，避免把旧表覆盖到后来修改的数据。

解析期间可以点击“取消解析”，等待取消反馈；取消后不会提交业务资料。当前测试覆盖取消行为，但大型文件在真实浏览器中两秒内反馈的门槛尚未验收。

导出业务表后，保留原报价编号与导出修订编号，便于改表回流时显示基线。导出会验证文件后再报告完成。当前普通 XLSX 读写采用容量限制，超限会拒绝；尚未证明支持任意大型工作簿。真实 Excel/WPS 的完整修改回流，以及浏览器文件选择器到 OPFS 暂存、确认提交的业务导入链路仍待独立验收。

## 完整同步

在“文件与备份”点击“打开完整同步”。

- 导出：点击“生成同步包”，等待冻结快照、分卷生成和整包自验完成。传递完整生成的包，不要拆卷、改名内部文件或编辑内部工作簿。
- 导入：点击“选择并预览”，原生界面输入同步包完整路径，浏览器选择文件。系统验证全部分卷、修订关系、投影及与本地数据的合并结果。核对来源、修订数与摘要后，点击“备份并提交”。
- 取消预览不会提交业务数据。结构损坏、缺卷或不支持的版本会拒绝整个包；不要把失败的同步包改走普通业务导入。
- 解析期间可点击“取消解析”。提交失败且预览仍可重试时，点击“重试备份并提交”，沿用当前任务；若提示预览过期，则重新生成预览。

同步可能留下并行冲突，需要人工处理。导入完成后查看记录状态；浏览器完整同步的实际文件交互链路仍待独立验证。

## 冲突与关联修复

冲突记录及并行重定向记录的详情提供“处理冲突”。查看各个完整版本，明确选择后可继续编辑，再提交解决结果。选择已删除分支时，需要再次“确认删除”；重定向分支会进入明确的关联修复流程。并列版本保留在历史中；若其他窗口已修改，重新读取并核对，不重复提交旧选择。

供应商或产品重复时，在“文件与备份”选择“修复供应商关联”或“修复产品关联”：选择来源记录和保留记录，点击“核对最新内容与影响”，核对引用数量与保留记录的完整内容，勾选确认后提交。来源历史保留并指向保留记录。

需要处理重定向环、多分支或已删除记录时，开启“修复一组异常关联”，选择来源与保留记录，再用“添加异常记录”纳入需要一起修复的记录。明确填写保留记录的完整内容：此处空白表示清空，别名和分类每行一项。重新核对影响并确认后提交；失败时保留选择，重新核对最新内容后再确认。

## 备份与恢复

“创建完整备份”保存完整历史和导入记录。等待校验成功提示，并确认文件在所选位置可找到；浏览器提示发起下载时，仍需核对浏览器下载结果。业务 Excel 不能替代完整备份。

备份失败不会报告成功，已打开的输出会被中止。浏览器导入前的安全备份已记录持久位置并关联任务，但完整“导入前备份→关闭浏览器→重新定位读取”链路尚未独立验收；请继续保留站点存储之外的完整备份。

恢复会替换当前活动资料库，不是合并：

1. 点击“恢复备份”，输入完整备份路径或通过浏览器选择文件。
2. 等待完整校验，核对文件名、校验值、记录行数和来源版本。
3. 确认恢复后，系统先为当前资料库生成安全备份，再切换并重新打开；看到“完整备份已验证、切换并重新打开”才算完成。

取消确认会保留当前资料库。失败时读取提示；若应用已重新打开可用资料库，先核对记录。不要手动删除原库、候选库或恢复标记来绕过错误。

## 任务历史与错误恢复

“查看文件任务记录”展示业务导入和完整同步任务的状态、任务编号、基线及源摘要。可继续的任务提供“继续”；没有继续按钮时保留任务编号与错误信息。不要仅凭进度结束判断成功，应核对“已完成”与成功回执。

| 提示或现象 | 下一步 |
| --- | --- |
| 预览过期、资料库版本变化 | 重新读取并生成预览，再次核对选择。 |
| 原文件需要重新选择 | 选择原始文件；相同名称不代表内容相同，内容摘要不匹配时重建任务。 |
| 行校验失败或缺必填值 | 修正原表或映射；仅普通业务导入可明确排除错误行。 |
| 备份失败、空间或配额不足 | 保留源文件和任务；释放可确认无用的空间或选择有空间的位置后重试。不要清除站点数据释放空间。 |
| 文件选择取消 | 返回操作即可；取消不是成功导入。 |
| 查询读取失败 | 点击重试；错误状态不代表资料库为空。 |
| 提交后窗口中断 | 先重开应用并查看任务/成功回执，避免立即把同一资料当作全新记录再录入。 |
