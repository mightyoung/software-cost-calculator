# Rust 中心端首批交付执行计划

用户已于本轮明确授权在 `codex-backend` 按现有设计开始开发；直接执行与验证，不再增加设计审批。

**Goal:** 交付可运行、可恢复的公司资料中心，支持明确发布供应商与历史报价、查询版本及严格单向目录交换。

**Architecture:** 单个 Rust 服务，SQLite 事务存储。本网 HTTP 提供发布与检索；跨网使用带来源校验的自包含 JSON 文件包，A 生成、B 自动验证去重导入；同步默认关闭，可配置导出/导入角色并重启生效。

**Tech Stack:** Axum/Tokio、rusqlite bundled SQLite、serde、UUID、SHA-256/HMAC、TOML、tracing。只加入首批运行与测试所必需依赖，锁定 Cargo.lock。

**Spec:** `docs/design/2026-09-29-central-hub-research.md` 及本会话确认的发布范围、目录交换与配置开关。

## 合同与约束

部署中心负责来源 UUID，发布 ID 与版本独立于客户端数据库版本。重复 ID/版本相同内容幂等，不同内容冲突；输入快照保留原始十进制字符串和必要询价上下文。发布载荷不包含本地字段日志、凭据或未选资料。

本网接入使用部署级令牌而非账号平台；非回环监听必须配置令牌。跨网共享密钥与 API 令牌由环境读取，不写入交换包、示例或日志。支持单向导出/导入，进度只代表本地动作；开关重启生效，关闭不删除已投递文件。

## 特别检查

未完整文件不得半入库；相同身份不同内容不能覆盖；摘要不是身份认证；无回程不宣称远端接收；队列积压和磁盘失败可观察且不能误推进导出进度；接收保留内网本地来源记录。
